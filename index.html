Main Modules

3 Core Systems + AI + Notifications + Profile - Full Report Section 3

Smart Digital Notice Board
Module 1
Student Can:
  • View all notices
  • Search & Filter (Dept/Semester)
  • View details, Deadlines, Reminders
  • Receive notifications
  • Pinned notices
  • AI summary
Admin Can:
  • Create/Edit/Delete notices
  • Pin important, Set deadlines
  • Target Dept/Semester
  • Manage all, Dashboard stats
Complaint Management
Module 2

Categories: Classrooms, Computer Labs, Electricity, Wi-Fi, Furniture, etc.

Student:
  • Submit + description + upload images
  • Category + Track status + History + Updates
Submitted → Assigned → In Progress → Resolved
Admin:
  • View all, Filter by category/status
  • Assign to staff, Update status
  • Monitor pending/resolved
Lost & Found
Module 3
Student:
  • Report Lost Item, Report Found Item
  • Name/desc/images/location/date/time
  • Search/Filter listings, Claim submit, Item details
Admin:
  • Manage listings, Manage claims
  • Verify ownership, Remove inappropriate
  • Monitor users
